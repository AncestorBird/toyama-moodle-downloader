# Toyama Moodle Downloader

富山大学の「Moodle 専門科目/その他」から、選択した授業の資料を取得するツールです。GitHub Pagesで公開できるWeb版と、Pythonで動くCLI版があります。どちらもMoodle公式のモバイルAPIを使います。

対象サイト: https://moodle52.u-toyama.ac.jp/

大学が提供する公式ツールではありません。利用者自身のMoodleアカウントでアクセスでき、授業内容APIに掲載される資料が対象です。

## Web版（GitHub Pages）

Pythonの導入は不要です。公開されたページを開き、Moodleのユーザー名・パスワードでログインします。

1. 登録授業が一覧で表示されます。授業名・IDで検索し、取得する授業にチェックします。
2. 「まず取得予定の資料だけ確認する」で、保存前に対象資料を確認できます。
3. 「選択した授業の資料を取得」で、資料を授業・セクションごとのフォルダに整理したZIPを保存します。
4. 保存先はブラウザのダウンロード設定に従います。取得中は中止でき、個別の失敗は画面に表示します。

ブラウザのメモリ使用を抑えるため、1ファイル50 MB、1回の取得合計200 MBを上限としています。成功した資料だけをZIPにまとめ、失敗した資料は一覧で確認できます。取得済みファイルとの差分判定は行いません。大容量資料や差分取得にはCLI版を使ってください。

### パスワードの保存

ブラウザ標準のパスワードマネージャーを利用します。入力欄はユーザー名・現在のパスワードの自動入力に対応しています。

- Chrome / Edgeなど、Password Credential APIに対応したブラウザでは「このブラウザにパスワードを保存」を選べます。**ログインと授業一覧の取得に成功した後だけ**、ブラウザに保存を依頼します。保存の可否はブラウザの設定・操作によります。
- そのAPIがないブラウザではチェック欄を表示しません。Firefox / Safariなどの標準の保存案内・自動入力機能を利用してください。保存案内が必ず出るとは限りません。
- 次回はブラウザの保存済み情報を自動入力してログインできます。パスワードの変更・削除・同期は、ブラウザのパスワードマネージャーで管理します。
- 保存項目のサイト名は、このWeb版を公開したGitHub Pagesのドメインです。Moodle本体のドメインに保存した項目とは別に扱われます。

アプリ自身はパスワード・トークンをlocalStorage、sessionStorage、Cookieに保存しません。トークンはページを開いている間のメモリにのみ保持し、ログアウト・再読み込みで破棄します。ログアウトしても大学側のトークンは失効させません。

### 通信とプライバシー

認証情報とAPIリクエストは、ブラウザから `https://moodle52.u-toyama.ac.jp/` へHTTPSで直接送ります。認証用サーバーや外部の通信中継サービスは追加しません。資料のZIPもブラウザ内で作成します。認証情報・APIトークンをURLに含めず、別URLへの転送は拒否します。

GitHub Pagesはページ自体の配信に使われるため、通常のページアクセス情報はGitHubにも送られます。アプリに外部のアクセス解析はありません。ブラウザのパスワード同期や拡張機能は、それぞれの利用者の設定に従います。

Web版はMoodle側のCORS許可に依存します。ログイン・REST API・ファイル取得の各エンドポイントが、認証なしの応答で `Access-Control-Allow-Origin: *` を返すことを確認済みです。実アカウントでのログイン・資料取得は未検証です。Moodle側の設定変更や追加認証によっては利用できません。

### GitHub Pagesに公開する

リポジトリの管理者が次の手順を実行します。

1. GitHubのリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
2. この変更を `main` に反映します。`.github/workflows/pages.yml` がテスト・ビルド後に公開します。Actionsの **Test and publish GitHub Pages → Run workflow** からも実行できます。
3. Actionsの `deploy` ジョブが成功したら、その出力・環境画面に表示されるURLを開いて確認します。

標準のプロジェクトURLは `https://ancestorbird.github.io/toyama-moodle-downloader/` です。これは公開後の想定URLであり、このREADMEの追加だけでは公開されません。独自ドメイン・フォークでは、GitHub Pagesの設定に表示されるURLを使用してください。

APIキーやMoodleの認証情報をGitHub Secretsに登録する必要はありません。利用者が公開ページから各自のアカウントでログインします。依存パッケージはページと一緒にビルドされ、閲覧時に外部CDNから読み込む構成にはしていません。

### Web版の開発とテスト

Node.js 22.12以降が必要です。

```sh
npm ci
npm run dev

# 単体テスト（外部通信なし）
npm test

# ブラウザテスト（模擬API・模擬認証情報のみ）
npx playwright install chromium
npm run test:e2e

# 公開する静的サイトをdist/へ生成
npm run build
```

ブラウザテストはGitHub Pagesのプロジェクト配信パスで、ログイン、授業検索・選択、パスワード保存依頼、ZIPの中身、認証失敗、中止、モバイル表示を検証します。実際のパスワード保存の案内・自動入力は、利用するブラウザで別途確認してください。

## CLI版に必要なもの

- Python 3.11以降（追加パッケージは不要です）
- 富山大学Moodleのユーザー名・パスワード
- インターネット接続

CLI版は有料のAI APIやクラウドサービスを使いません。毎回ログインする対話式のツールで、認証情報の保存・定期実行は行いません。

## CLI版のダウンロードと実行

このリポジトリをGitでcloneするか、GitHubの「Code → Download ZIP」で取得し、ZIPの場合は展開します。

### macOS

`Moodle資料取得.command` をダブルクリックします。実行権限がない場合やPythonが見つからない場合は、下記のターミナル用コマンドを使ってください。

### Windows / Linux / macOSのターミナル

ターミナルでこのフォルダに移動して実行します。

```sh
python3 tools/moodle_download.py
```

Windowsでは、環境に応じて `python3` の代わりに `py -3` または `python` を使います。

1. Moodleのユーザー名とパスワードを手元のターミナルに入力します。パスワードは入力中も表示されません。
2. 登録している授業のID・授業名が表示されます。
3. 取得する授業のIDを入力します。複数なら `123,456` のように指定します。
4. 資料を `moodle_downloads/` に保存します。IDを入力せずEnterを押すと、取得せずに終了します。

保存例:

```text
moodle_downloads/
  授業ID_授業名/
    セクションID_第1回/
      教材ID_配布資料/
        識別子_資料.pdf
```

同名資料を区別するため、ファイル名の先頭に識別子を付けます。変更のない取得済み資料は省略し、更新された資料は別名で保存します。手元のファイルは上書き・削除しません。

## 最初に接続・授業一覧だけ試す

```sh
# ログインせず、Moodleへの接続とAPI設定だけ確認
python3 tools/moodle_download.py --check

# ログインと登録授業一覧だけ確認
python3 tools/moodle_download.py --list

# 取得予定の資料一覧だけ確認（ファイルを保存しません）
python3 tools/moodle_download.py --dry-run

# 指定した授業の資料を取得（IDは自分の授業一覧で確認）
python3 tools/moodle_download.py --course 123

# 複数授業を指定
python3 tools/moodle_download.py --course 123 --course 456
```

保存先を変える場合は `--output /path/to/folder` を指定できます。独自の保存先はこのリポジトリの `.gitignore` では保護されない場合があるため、共有するコードとは別の場所を指定してください。

## 情報の扱い

- ユーザー名・パスワードは `https://moodle52.u-toyama.ac.jp/login/token.php` にHTTPSのPOSTで送信します。
- パスワードと取得したAPIトークンはファイルに保存しません。トークンをURLにも入れません。
- 通信先は上記のMoodleに限定し、別URLへの転送は行いません。資料をAIや他の外部サービスに送る処理はありません。
- このプログラムが呼び出すAPIは、サイト情報・本人の登録授業・授業内容の取得に限定しています。課題提出や履修登録、成績変更の操作はありません。
- ただし、発行されるモバイルAPIトークン自体が読み取り専用とは限りません。終了時に大学側のトークンを失効させる処理はありません。
- Moodle側には認証トークンやアクセスログが残る可能性があります。
- 取得資料と履歴は暗号化せず手元に保存します。iCloudなどの同期対象フォルダに置くと、そのサービスにもコピーされる可能性があります。
- 標準の保存先 `moodle_downloads/`、`.env`、一般的な認証情報ファイルはGitから除外しています。除外設定は暗号化やアクセス制御ではなく、強制的なGit追加や別サービスへの共有は防げません。
- プログラムを共有する際はコードだけを渡し、利用者はそれぞれ自分のアカウントで実行してください。パスワード・トークン・取得した授業資料をGitHubのIssueなどに貼らないでください。

## 対応範囲と制限

- 授業内容APIに掲載された、Moodle内のファイルを取得します。
- 外部サイト、ストリーミング動画、APIに掲載されない添付ファイルなどは対象外です。授業ページ全体を保存するものではありません。
- 他の富山大学Moodleサイトや、他大学のサイトは現在の対象外です。
- アカウントの権限や追加認証によってAPIを利用できない場合は、エラーを表示して終了します。認証失敗の自動再試行はしません。
- このMacで公開設定への実接続と模擬テストを確認しています。実アカウントのログイン・資料取得、Windows/Linuxでの実行は共有版作成時点で未検証です。

## テスト

