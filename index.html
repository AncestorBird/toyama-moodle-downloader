情報の扱い・対応範囲

GitHub Pagesで動く静的なWebアプリです。認証情報・トークン・資料をアプリのサーバーへ送信せず、Moodleに直接接続します。外部のアクセス解析は使用しません。

アプリはパスワード・トークンをlocalStorageやCookieに保存しません。ブラウザのパスワード保存・同期は、ご自身のブラウザ設定で管理してください。保存された項目の削除もパスワードマネージャーで行えます。

ログアウト・ページ再読み込みで、この画面の認証トークンは破棄されます。大学側のトークンを失効させる操作は行いません。発行されるAPIトークン自体が読み取り専用とは限りません。

授業内容APIに掲載されたMoodle内のファイルが対象です。外部サイト・ストリーミング動画・追加認証には対応しません。Web版は毎回新しいZIPを作成し、取得済みファイルとの差分判定はしません。大容量資料や差分取得にはGitHubのCLI版を利用できます。

課題確認は、対象の年度・クォーター・検索条件に合う授業のMoodle課題と提出状態を自動で読み取ります。小テスト・紙提出・非公開や閲覧権限のない課題は対象外です。課題を提出・変更する操作は行いません。取得した提出状態はログアウト・再読み込みで消去されます。

このページの配信元としてGitHub Pagesにも通常のアクセス情報が送られます。ブラウザの拡張機能やパスワード同期機能は、それぞれの設定に従います。
